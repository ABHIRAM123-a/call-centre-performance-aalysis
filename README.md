# call-centre-performance-aalysis
### Project Title / Headline

📞 Call Centre Performance & Customer Analytics Dashboard

An interactive data analytics dashboard designed to evaluate call centre performance, representative productivity, customer satisfaction, purchase amounts, call duration, and geographic customer distribution. The dashboard helps identify top-performing representatives, customer trends, and areas for improving call centre efficiency.

### Short Description / Purpose

The Call Centre Performance Dashboard is an interactive Excel-based analytics solution developed to monitor and analyze call centre operations. It provides insights into call volumes, purchase amounts, call duration, customer satisfaction, representative performance, customer demographics, and city-level activity to support data-driven operational decisions.

### Tech Stack

The dashboard was built using the following tools and technologies:

📊 Microsoft Excel – Main platform used for data analysis and dashboard development.
📂 Excel Data Cleaning & Transformation – Used to prepare and organize raw call centre data.
📈 Pivot Tables – Used to summarize calls, purchase amounts, representatives, cities, ratings, and customer information.
📊 Pivot Charts – Used to visualize trends and performance comparisons.
🔢 Excel Formulas & Calculations – Used for KPIs, rankings, percentages, and performance metrics.
🎛️ Interactive Filters/Slicers – Used to dynamically analyze representatives, locations, and customer segments.
🖼️ Dashboard Design – Combined KPIs, charts, tables, and representative-level insights into a centralized dashboard.

### Features / Highlights
• Business Problem

Call centres generate large amounts of customer interaction data, but raw call records can make it difficult for managers to quickly understand representative performance, customer satisfaction, call volumes, and revenue generated through customer interactions.

Key questions such as:

Which representatives handle the most calls?
Which representative generates the highest purchase amount?
How satisfied are customers with the service?
Which cities generate the highest call volume?
Which days or months have the highest number of calls?
How does call duration relate to customer satisfaction?
What percentage of calls are handled by each representative?

can be difficult to answer from raw data.

• Goal of the Dashboard

The goal of the dashboard is to provide a centralized analytical view that:

Monitors overall call centre performance.
Compares representative productivity.
Tracks purchase/revenue generated through calls.
Evaluates customer satisfaction.
Identifies call volume trends by month and day.
Analyzes customer demographics and geographic distribution.
Helps management identify high- and low-performing areas.
